# Exercício 13.3 — Prompt injection defensivo
A string do log tenta substituir a tarefa de classificação por uma ordem de responder NORMAL. O classificador delimita o log como dado não confiável, fixa as instruções no papel de sistema e valida a resposta contra `NORMAL`, `SUSPEITO` e `CRITICO`. Respostas inválidas ou falhas de API acionam regras locais. O script imprime a classificação obtida e indica se a tentativa de injeção aparentemente teve efeito. **Não há resultado real de API documentado antes da execução.** Delimitadores ajudam, mas não garantem proteção absoluta; a classificação deve ser tratada como sinal auxiliar.
